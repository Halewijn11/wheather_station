# Kill Your Darlings

A cutting pass, run with the user via [Grilling](../../../inbox/resources/matt_pockock_skills/grilling/SKILL.md) — the same relentless, nothing-left-unasked interview this project already uses for outline agreement and paragraph review. This skill is that mechanism pointed at a narrower question: not "what should this say" but "what stays and what goes."

Takes a set of candidates as its argument — competing ideas for a section, or a paragraph-draft ticket's posted versions. Fails without one; this skill doesn't invent the candidate set itself.

## Two shapes, same mechanism

- **Early — pruning a wide field.** Many competing ideas or passages exist and most need to go before drafting narrows further. The frontier question for each candidate is *keep or cut, and why* — grilled one round at a time exactly as Grilling specifies, with a recommended answer attached to each.
- **Late — choosing one complete version.** Drafting is otherwise done; several complete, streamlined alternatives exist and the goal is picking one, not trimming within it. Frame the frontier as pairwise or full-set comparisons ("prefer A or B, and why") rather than independent keep/cut calls, since the candidates compete with each other rather than standing alone.

Decide which shape applies before running Grilling — it changes how the frontier's questions are framed, not whether Grilling itself applies.

## Process

1. State which shape this pass is (early pruning or late selection) and why, in one sentence.
2. Run Grilling against the candidate set using that shape's framing. A cut decision needs a stated reason, not just a verdict — "cut, redundant with paragraph 2" is a keep/cut answer; "cut" alone is not.
3. When the frontier is empty, report what was cut and what survived, each with its one-line reason, then stop — this skill doesn't rewrite or merge the survivors, that's the drafting step's job.

## Where this plugs in

If the candidates came from a paragraph-draft ticket, post the outcome as a comment on that ticket the same way [paragraph-draft](../paragraph-draft/SKILL.md)'s own rounds are posted — the cut decision becomes part of that ticket's record, not just chat history.
